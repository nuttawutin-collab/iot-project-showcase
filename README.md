# IoT คืออะไร? — สำหรับคนไม่เคยเข้าใจมาก่อน

เว็บไซต์นำเสนอเนื้อหาจากเอกสาร IoT.pdf ในรูปแบบหน้าเว็บเลื่อนอ่าน 8 บท ออกแบบให้เหมาะกับทั้งหน้าจอคอมพิวเตอร์และมือถือ

## เปิดดูในเครื่อง
เปิด `index.html` ด้วยเว็บเบราว์เซอร์

## เนื้อหา
1. IoT คืออะไร
2. การเชื่อมต่ออุปกรณ์ อินเทอร์เน็ต และผู้ใช้
3. ตัวอย่าง Smart Watch และ Smart Speaker
4. ตัวอย่าง Smart Home
5. ประโยชน์ในชีวิตประจำวัน
6. Smart City
7. ความปลอดภัยและความเป็นส่วนตัว
8. สรุปแนวคิด IoT
