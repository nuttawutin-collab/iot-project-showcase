# IoT Project Showcase

หน้าเว็บแนะนำโปรเจกต์ IoT สร้างด้วย HTML และ CSS แบบ responsive พร้อมเผยแพร่ผ่าน GitHub Pages

## เปิดดูในเครื่อง
เปิด `index.html` ด้วยเว็บเบราว์เซอร์

## ปรับแต่งก่อนเผยแพร่
แก้ชื่อโปรเจกต์ ข้อความ รายละเอียดทีม และลิงก์ GitHub ใน `index.html` ให้ตรงกับผลงานจริง

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository บน GitHub และอัปโหลดไฟล์ในโฟลเดอร์นี้
2. เปิด **Settings → Pages**
3. เลือก **Deploy from a branch**, เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
4. รอให้ GitHub Pages แสดง URL ของเว็บไซต์ในหน้า Settings → Pages
