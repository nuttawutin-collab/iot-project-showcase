# IoT — Presentation

นำเสนอไฟล์ IoT.pdf ในรูปแบบสไลด์เต็มจอ 8 หน้า ภาพแต่ละหน้าถูกเรนเดอร์จากต้นฉบับเพื่อคงรูปแบบ สี ภาพประกอบ และตำแหน่งข้อความให้ตรงกับ PDF

## เปิดในเครื่อง
เปิด `index.html` ด้วยเว็บเบราว์เซอร์

## ควบคุมสไลด์
- ใช้ปุ่มลูกศรบนหน้าจอหรือแป้นพิมพ์ `←` / `→`
- กด `Home` เพื่อกลับหน้าแรก และ `End` เพื่อไปหน้าสุดท้าย
- กดปุ่มเต็มหน้าจอเพื่อแสดงสไลด์แบบ presentation
